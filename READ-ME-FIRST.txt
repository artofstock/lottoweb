원본: 로또추첨기FHD v1.9.11 (Python/Tkinter)


[ 바로 쓰는 법 ]

  index.html 을 더블클릭하세요. 브라우저에서 바로 열립니다.
  파이썬도, 설치도, 인터넷 연결도 필요 없습니다.

  ※ 로컬에서 더블클릭으로 열면 크롬 보안 정책 때문에
    [조건] 탭의 조건 탐색과 [검정] 탭의 공정성 검정이
    한 스레드로만 돌아 약 5배 느립니다 (화면에 안내가 뜹니다).
    아래처럼 웹에 올리면 정상 속도가 나옵니다.


[ 웹에 올리는 법 - GitHub Pages, 무료 ]

  1. github.com 에서 새 저장소를 만든다
  2. index.html 파일 하나만 업로드한다 (드래그 앤 드롭)
  3. Settings - Pages - Source 를 main 브랜치로 지정
  4. 몇 분 뒤 https://<아이디>.github.io/<저장소>/ 로 열린다

  그 주소를 휴대폰에서 열어도 그대로 동작합니다.


[ 방송(OBS)에서 쓰는 법 ]

  [설정] 탭 - 방송 모드 - [링크 만들기] 를 누르면
  회차 / 구멍수 / 게임수 / 소리 설정이 담긴 주소가 만들어집니다.
  그 주소를 OBS 의 [브라우저] 소스에 붙여넣으면 됩니다.

  B 키로 언제든 방송 모드를 켜고 끌 수 있습니다.
  OBS 소스 속성에서 "페이지가 보이지 않을 때 소스 종료"는 꺼 두세요.


[ 폴더 설명 ]

  index.html      실제로 쓰는 파일. 이것 하나면 됩니다.
  README.md       자세한 설명 (기능, 원본에서 고친 것, 제약)
  dev/            고쳐 쓰고 싶을 때만 보세요.
                  dev/src/ 를 수정한 뒤 dev/build.js 를 돌리면
                  index.html 이 다시 만들어집니다.
  original/       참고용 원본 파이썬 파일
